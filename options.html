OpenChamber Usage

OpenCode Go API key

Used only to read your quota directly from opencode.ai when you are not on the OpenChamber page. It is stored locally (chrome.storage.local) and never sent anywhere else.

Find the key in ~/.local/share/opencode/auth.json under the opencode-go entry, or from your OpenCode Go account.

What each mode shows

  • On the OpenChamber page — quota, per-turn cost / cache hit / i-c/o, peak timer. No key needed.
  • Toolbar popup (anywhere) — quota + peak timer. Needs the key above. Per-turn data needs OpenChamber.
