OpenChamber Usage

OpenCode Go key vault

The key is encrypted with your passphrase (AES-GCM, PBKDF2-SHA256). Only the ciphertext is stored; the key is never shown again and cannot be recovered if you forget the passphrase. Unlocked, it lives only in memory and auto-locks after 15 minutes. It is used only to call opencode.ai.

Find the key in ~/.local/share/opencode/auth.json under the opencode-go entry, or from your OpenCode Go account.

OpenChamber server

Where OpenChamber runs. Default is http://localhost:3000. On Tailscale, enter your tailnet address, e.g. http://100.64.0.5:3000 or http://nuc.tailnet.ts.net:3000. The overlay is then injected on that origin.

What each mode shows

  • On the OpenChamber page — quota, per-turn cost / cache hit / i-c/o, peak timer. No key needed.
  • Toolbar popup (anywhere) — quota + peak timer, using the vault above. Per-turn needs OpenChamber.
